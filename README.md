# Programme-bancaire-Cobol & Formation COBOL — Du débutant à l'emploi

## 🎯 Objectif de la formation

Apprendre COBOL depuis zéro, comprendre le code, écrire et tester des programmes, manipuler des fichiers et découvrir l'environnement professionnel mainframe.

Chaque notion sera étudiée progressivement, avec des explications, des exercices pratiques et des projets.

**Méthode :** comprendre → coder → exécuter → tester → expliquer.

---

## 1. Les bases du langage

- [ ] Comprendre la structure d'un programme COBOL
- [ ] `IDENTIFICATION DIVISION`
- [ ] `PROGRAM-ID`
- [ ] `DATA DIVISION`
- [ ] `WORKING-STORAGE SECTION`
- [ ] `PROCEDURE DIVISION`
- [ ] Utiliser `DISPLAY`
- [ ] Comprendre `STOP RUN`
- [ ] Comprendre les points et la syntaxe
- [ ] Compiler et exécuter un programme

## 2. Les variables et les données

- [ ] Comprendre ce qu'est une variable
- [ ] Déclarer une variable avec `01`
- [ ] Comprendre `PIC`
- [ ] Utiliser `PIC X` pour du texte
- [ ] Utiliser `PIC 9` pour des chiffres
- [ ] Utiliser `VALUE`
- [ ] Différencier le nom d'une variable et son contenu
- [ ] Déclarer plusieurs variables
- [ ] Modifier une variable
- [ ] Comprendre les décimales avec `V`
- [ ] Comprendre les formats d'affichage
- [ ] Comprendre les longueurs des champs

## 3. La saisie et l'affichage

- [ ] Utiliser `ACCEPT`
- [ ] Afficher du texte avec `DISPLAY`
- [ ] Afficher le contenu d'une variable
- [ ] Lire plusieurs valeurs
- [ ] Afficher un résultat calculé
- [ ] Contrôler les données saisies

## 4. Les calculs

- [ ] `ADD` — addition
- [ ] `SUBTRACT` — soustraction
- [ ] `MULTIPLY` — multiplication
- [ ] `DIVIDE` — division
- [ ] `COMPUTE` — calcul avec une expression
- [ ] Calculer un total
- [ ] Calculer un pourcentage
- [ ] Calculer une prime ou une retenue
- [ ] Manipuler des montants décimaux
- [ ] Comprendre les arrondis et les résultats numériques

## 5. Les conditions

- [ ] Comprendre les comparaisons : égal, différent, supérieur, inférieur
- [ ] Utiliser `IF`
- [ ] Utiliser `ELSE`
- [ ] Terminer une condition avec `END-IF`
- [ ] Combiner plusieurs conditions
- [ ] Utiliser `AND` et `OR`
- [ ] Utiliser `EVALUATE`
- [ ] Gérer les erreurs de saisie avec des conditions

## 6. Les répétitions et l'organisation du code

- [ ] Comprendre pourquoi répéter des instructions
- [ ] Utiliser `PERFORM`
- [ ] Répéter une opération plusieurs fois
- [ ] Comprendre les paragraphes
- [ ] Appeler un paragraphe avec `PERFORM`
- [ ] Organiser un programme en plusieurs étapes
- [ ] Éviter les répétitions inutiles

## 7. Les données utilisées en entreprise

- [ ] Comprendre les identifiants et les codes
- [ ] Manipuler des dates
- [ ] Manipuler des montants financiers
- [ ] Comprendre les champs numériques et alphanumériques
- [ ] Vérifier la validité d'une donnée
- [ ] Détecter les données manquantes ou incorrectes
- [ ] Comprendre les formats de données métier
- [ ] Comprendre les groupes de données et les enregistrements

## 8. Les fichiers COBOL

- [ ] Comprendre le rôle des fichiers
- [ ] Comprendre la `FILE SECTION`

- [ ] Ouvrir un fichier avec `OPEN`

- [ ] Fermer un fichier avec `CLOSE`
- [ ] Détecter la fin d'un fichier
- [ ] Traiter plusieurs enregistrements
- [ ] Calculer des totaux à partir d'un fichier
- [ ] Produire un rapport de sortie

## 9. Les tests et la correction des erreurs

- [ ] Comprendre les messages du compilateur
- [ ] Corriger une erreur de syntaxe
- [ ] Détecter une erreur de calcul
- [ ] Tester un résultat attendu
- [ ] Tester les valeurs limites
- [ ] Tester les données incorrectes
- [ ] Comprendre les erreurs à l'exécution
- [ ] Vérifier un programme après modification
- [ ] Expliquer le fonctionnement de son propre code

## 10. Les sous-programmes et les notions avancées

- [ ] Organiser le code en paragraphes
- [ ] Comprendre les sous-programmes
- [ ] Comprendre `CALL`
- [ ] Comprendre le passage de données entre programmes
- [ ] Comprendre les structures de données plus complexes

## 11. L'environnement professionnel mainframe

- [ ] Comprendre ce qu'est un mainframe
- [ ] Comprendre le traitement batch
- [ ] Apprendre les bases de JCL
- [ ] Comprendre les fichiers d'entrée et de sortie d'un traitement batch
- [ ] Apprendre les bases de SQL
- [ ] Comprendre les tables, lignes et colonnes
- [ ] Utiliser `SELECT`, `INSERT`, `UPDATE` et `DELETE` en SQL
- [ ] Découvrir DB2
- [ ] Découvrir CICS si nécessaire pour les postes visés

## 12. Les projets pratiques

- [ ] **Projet 1 — Calcul de salaire :** salaire de base, prime, retenue et salaire final
- [ ] **Projet 2 — Gestion de stock :** articles, quantités, stock restant et alertes
- [ ] **Projet 3 — Transactions :** lecture, contrôles, totaux et rapport
- [ ] **Projet 4 — Traitement de fichier :** lire des enregistrements et produire un résultat
- [ ] **Projet 5 — Projet final :** application organisée, testée et documentée

## 13. Préparation à l'emploi

- [ ] Expliquer chaque partie d'un programme
- [ ] Écrire un programme simple sans assistance constante
- [ ] Lire et modifier du code existant
- [ ] Corriger des erreurs
- [ ] Présenter au moins un projet personnel
- [ ] Préparer un CV adapté aux postes ciblés
- [ ] Rechercher des offres COBOL junior et des formations avec recrutement
- [ ] Se préparer aux exercices techniques et aux entretiens

## ✅ Règles de progression

- Ne pas brûler les étapes.
- Comprendre chaque instruction avant de passer à la suivante.
- Exécuter les exercices dans un compilateur COBOL.
- Corriger les erreurs et comprendre leur origine.
- Cocher une notion lorsqu'elle a été comprise et pratiquée.
- Réaliser les projets pour consolider les connaissances.

**Objectif final :** savoir écrire, tester, expliquer et modifier des programmes COBOL simples, puis acquérir progressivement les compétences utilisées dans les environnements professionnels.
